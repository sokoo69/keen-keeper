# Keen Keeper

Keen Keeper is a personal relationship tracker that helps you stay in touch with the people who matter most. Instead of forgetting check-ins, you can quickly log interactions, review your timeline, and see simple analytics for your communication habits.

## Technologies Used

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- Recharts (analytics charts)
- react-hot-toast (feedback toasts)
- lucide-react 

## 3 Key Features

1. Friend Management Dashboard
Browse a clean home dashboard with friend cards, status badges, and quick relationship summaries.

2. Quick Check-In + Timeline
Log calls, texts, or video check-ins from each friend profile and instantly see them in a searchable, filterable timeline.

3. Friendship Analytics
Track total interaction types with a visual pie chart so you can understand how you are communicating over time.
